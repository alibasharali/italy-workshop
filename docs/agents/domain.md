# Domain docs

Single-context repo.

- **Glossary and rules:** `docs/TRONDER_LEIKAN.md`. It plays the role the mattpocock skills call `CONTEXT.md`. Use its Norwegian terms (turnering, spill, deltaker, arrangør, tilskuer, pallplass) in domain language and test names.
- **ADRs:** `docs/adr/NNNN-<slug>.md`, starting with 0001–0005 for the decisions the code already embodies. New ones are added when a spec makes a decision that outlives the story. If you contradict an ADR, say so explicitly and don't override it silently.
